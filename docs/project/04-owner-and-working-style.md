# 04 — The Owner and How to Work Together

## About the owner

- The owner is not an AI expert, and does not yet know C++ or graphics, but believes they can build this project.
- The owner is learning 2D/3D image generation and animation while building the project.
- The project is also an **education** project.

## How to explain things

- Write all explanations and suggestions in a **beginner-friendly** way.
- Explain new words the first time they appear.
- Say **why** a choice is made, not only what it is.

## Decisions and suggestions

- Treat the files in this folder as the owner's decisions.
- Mark your own ideas as **Suggestion**, and let the owner decide.
- If something here is unclear or seems to conflict, ask the owner.

## Where these rules come from

These rules are copied from the project's shared notes (the PromptQL wiki), so any AI tool can read them inside the repository. When a rule changes, update these files too.
